# Agent Worklogs & Session Notes

This directory stores work session logs written by agents and human developers.

## File Naming Convention
Every note must follow this naming pattern:
```
YYYY-MM-DD-<short-descriptive-topic>.md
```
*Example:* `2026-11-07-setup-agent-framework.md`

## Instructions for Agents
1. Copy the structure from [TEMPLATE.md](TEMPLATE.md).
2. Fill out every section honestly and concisely. Include file links and commands run.
3. Once created, register the note in the table inside [../../AGENTS.md](../../AGENTS.md).
4. Update the active checklist in `AGENTS.md` before concluding your turn.
